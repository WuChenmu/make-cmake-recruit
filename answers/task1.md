# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
    将头文件内容插入文件中，将宏替换成对应的内容，对#ifdef、#ifndef、#endif 等操作以确定哪些代码保留哪些不要
2. 编译
    拆分代码成词元；分析语法是否正确，如括号是否匹配、分号是否正确；检查类型是否匹配，如赋值前后数据类型是否一致；生成中间代码，进行代码优化，如优化循环、删除死代码；最终输出汇编指令代码
3. 汇编
    将汇编指令翻译成二进制机器码（0和1）；生成重定位表，记录待填充的地址，如调用的“printf”但是不知道printf在哪里就做个标记待处理。
4. 链接
    将目标文件和库文件合并，生成可执行文件.将调用的外部函数解析，找到对应的定义；在重定位表对应位置填充正确的内容

建议控制在 300～500 字，不需要展开复杂细节。
