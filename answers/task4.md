# Task 4：思考题

## 1. Make 和简单的 build.sh 有什么区别？

Make可以分析文件是否进行了修改，只重新编译修改了的文件；而build.sh会重新编译所有的文件，更耗时。
当.h头文件修改时，Make可以自动重新编译所有的引用了该头文件的程序。
能够并行编译，充分发挥多核CPU的性能。
如果中途报错了，修改后能接着上次的进度继续，不需要全部重来。

## 2. CMake 是编译器吗？

执行 `cmake --build build` 时，最终是谁在编译 C 源文件？

CMake不是编译器。真正编译代码的是底层的构建工具调用编译器。

## 3. 为什么不希望每次都重新编译所有 `.c` 文件？

编译文件耗时大，重新编译所有 `.c` 文件会无意义的消耗时间和CPU占用。只修改一个文件，其他的都没变化，编译结果也是一样的，没必要反复进行编译操作。
